バックグラウンドタスクとサブエージェント

出典: antigravity.google/docs/cli-subagents（公式ドキュメントの日本語要約）

時間のかかるビルド、複数ファイルのコード生成、リサーチの一括処理を並列のバックグラウンドエージェントに委任し、自分のプログラミングの流れを止めずに作業を続けます。

非同期実行モデル

開発者の速度を最大化するため、Antigravity CLI はマルチスレッドの非同期実行アーキテクチャを採用しています。長時間のビルド、大規模なコードベースの検索一括処理、複雑な複数ファイルの編集の間にターミナルセッションをロックする代わりに、主エージェントはこれらの操作を並列のサブエージェントやバックグラウンドのタスクに委任します。

この委任モデルにより、レイテンシの高い AI 処理を待つ必要がなくなります。複数の自律的なバックグラウンドスレッドが並行して検証タスクを実行している間も、コードの作成、プロンプトの送信、ファイルの確認を続けられます。

エージェントの管理: /agents パネル

現在のエージェント階層は、インタラクティブなターミナルインターフェースを通じて完全に可視化・管理できます。

パネルを開く

プロンプトで /agents と入力して Enter を押すと、インタラクティブなエージェントマネージャーパネルが開きます。

パネルの概要

パネルには、実行中・完了・終了・失敗したすべてのバックグラウンドエージェントのライブチェックリストが表示されます。

  • 識別子（Identifier）: 対象サブエージェントの一意の ID。
  • 役割（Role): エージェントの専門的な役割（「Codebase Researcher」や「Database Debugger」など）。
  • 状態（State）: ライブのステータス表示（running、done、killed、error）。
  • ステップ（Step）: 現在実行中のツールや推論ステップのリアルタイムな要約。

詳細な監視（ディープダイブ）

特定のバックグラウンドエージェントの内部的な推論、思考、ログを検査するには、次の手順を行います。

  1. /agents パネルを開き、↑/↓ で対象のエージェントを選択します。
  2. Enter を押してサブエージェント詳細ビューを開きます。
  3. この全画面ビューには、サブエージェントの推論ログ全体（プライベートな内部思考、ツール呼び出し、実行出力を含む）が表示されます。
  4. Esc を押すと、ビューを終了してメインのエージェントマネージャーの一覧に戻ります。

/tasks によるバックグラウンドタスクの監視

直接のシェルコマンド、テストスイート、/btw 経由で開始した単純なバックグラウンドクエリなど、エージェントによらないバックグラウンド操作には /tasks コマンドを使用します。

/tasks

タスクの追跡リストでは、次のことができます。

  • 標準的な非対話型のバックグラウンドプロセスを追跡する。
  • ↑/↓ でタスクを選択し、Enter を押して標準出力（stdout）のログを表示する。
  • 暴走したターミナルプロセスを安全に終了する。

キーボード操作の効率化

サブエージェントが手動の操作やツールの承認を必要とする際のコンテキスト切り替えの手間を減らすため、Antigravity CLI は効率的なショートカット経路を統合しています。

詳細への「テレポート」ナビゲーション（Ctrl+J）

サブエージェントが承認の必要なツール（ファイルの書き込みやデータベースマイグレーションの実行など）に遭遇すると、ステータスバーの通知が点滅します。

  • メインのプロンプトパネル内で Alt+J を押すと、現在の会話から、承認待ちの次のサブエージェントの詳細ビューへ即座に「テレポート」します。
  • アクションを承認または却下し、Esc を押すと主スレッドへテレポートして戻ります。

「ファストパス」での承認（Ctrl+K）

作業中のワークスペースを離れずにエージェントのアクションを即座に承認するには、次の手順を行います。

  1. アクティブなプロンプトボックスのすぐ上に表示されるインラインのステータス通知を確認します。これは保留中のアクションを要約します（例: Subagent 12 asks to run "npm test"）。
  2. Ctrl+K を押すと、パネルを切り替えたりオーバーレイを開いたりせずに、保留中のファストパスアクションを即座に承認できます。

次のステップ

シェルの表示挙動を設定し、構成プロファイルをカスタマイズします。

  • 設定、表示、キーバインド: キーマップ、バッファリング、JSON ルールをカスタマイズします。
  • 権限とサンドボックス: バックグラウンドプロセスにセキュリティの封じ込め領域を適用します。
  • プラグインとスキル: 独自のカスタムスキルやスラッシュコマンドを作成します。
