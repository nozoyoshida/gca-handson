agy CLI を活かす追加ハンズオン案（メニュー）

実装版（手順つき）→ 発展ハンズオン
このページについて
以下の案は 発展ハンズオン（handson-advanced.html） としてすでに手順化済みです。本ページは「どの案がどの発展モジュールに当たるか」を一覧する早見メニューです（題材は基礎ハンズオンと同じ「お問い合わせ管理 API」）。

案 → 発展モジュール 対応表

案概要主に使う agy 機能対応モジュール区分
A 並列サブエージェントで一括改善複数の改善を並行実行し監視・承認/agents /tasks ctrl+k ctrl+jM3必修
B 権限 & サンドボックスで安全運用allow/deny/ask とサンドボックスで実行を制御permissions enableTerminalSandboxM1必修
C -p ワンショットで CI / Git フック非対話実行を自動化へ組み込むagy -p ... --cwdM2必修
D スキル / プラグインで配布規約・定型作業をチームに配る/skills .agents/skills/ pluginsM4必修
E MCP 連携外部 API / DB をエージェントに接続/mcp .agents/mcp_config.jsonM5任意
F 視覚デバッグスクショを貼って UI 崩れを直すctrl+vM6任意
G /fork で A/B 比較実装方針を分岐して比較・巻き戻し/fork /resume /rewindM7任意
既存ハンズオンへの差し込み方
低コストでの拡張は、B（権限/サンドボックス）を Ch.4 の発展、C（-p 自動化）を Ch.5 の発展として差し込むのがおすすめです。半日ワークショップにするなら A・D を独立セッションとして追加してください。詳細手順は 発展ハンズオン を参照。
