ウィンドウタイトル

出典: antigravity.google/docs/cli-title（公式ドキュメントの日本語要約）

動的なウィンドウタイトルの設定、カスタムスクリプト構成のマッピング、JSON 状態出力の整形を行い、ターミナルヘッダーをカスタマイズします。

概要

ターミナルウィンドウタイトル機能は、エージェントの詳細、アクティブなワークスペースのベース名、アクティブな会話のパラメータを、ターミナルエミュレータのタイトルバーに表示します。これにより、ターミナルウィンドウが最小化されていたりフォーカスされていなかったりする場合でも、エージェントの進捗を監視できます。

対話型の切り替え

  • 構文: 
    /title [on|off]
  • プロンプトボックスで /title と入力して Enter を押すと、機能のオン・オフが切り替わります。
  • /title on または /title off と入力すると、状態を明示的に設定できます。

カスタムタイトルスクリプト

ウィンドウタイトルの整形をカスタマイズするために、アクティブな TUI 状態の詳細をカスタムシェルスクリプトへ渡すことができます。

設定

~/.gemini/antigravity-cli/settings.json ファイルに title 設定ブロックを追加します。

{
  "title": {
    "type": "command",
    "command": "~/.gemini/antigravity-cli/title.sh"
  }
}

エージェントの状態が変化するたびに、TUI はあなたのコマンドスクリプトを実行し、詳細な状態 JSON ペイロードをスクリプトの stdin に直接パイプし、stdout から整形済みの文字列を読み取って、ターミナルウィンドウタイトルを更新します。印字不可能な文字や ANSI エスケープシーケンスは、レンダリング前に自動的に取り除かれます。

JSON 状態ペイロードのスキーマ

JSON 状態ペイロードは、カスタムステータスラインスクリプトに送られるものと同一です。cwd、conversation_id、agent_state、vcs の詳細などを表す詳細なプロパティが含まれます。完全なプロパティ一覧は ステータスラインのスキーマ を参照してください。

サンプルスクリプト

完全でレイアウト適応型のスクリプトを、公式の GitHub 上の title.sh の例 からダウンロードできます。このスクリプトはアクティブなワークスペースフォルダのベース名を抽出し、ライブのエージェント状態と会話セッションのプレフィックスを含む構造化されたターミナルタイトルを描画します。

スクリプトを ~/.gemini/antigravity-cli/title.sh に保存し、実行可能にします。

chmod +x ~/.gemini/antigravity-cli/title.sh

関連項目

  • ステータスラインのカスタマイズ: 動的な TUI ステータスバーをカスタマイズします。
  • 設定（settings.json）: キーボードホットキーとバッファをカスタマイズします。
  • 権限とサンドボックス: 安全なディレクトリ権限を管理します。
