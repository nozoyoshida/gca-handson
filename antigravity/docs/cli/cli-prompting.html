プロンプトと操作

出典: antigravity.google/docs/cli-prompting（公式ドキュメントの日本語要約）

基本的な操作パターン、複数行入力のワークフロー、セッションの中断操作、ターミナルへのメディア貼り付けを習得します。

プロンプトボックス

Antigravity CLI は、ターミナル画面の最下部に固定表示されるプロンプトパネルを備えています。このパネルでは、通常の入力、複数行のスクリプト、メディアの直接貼り付けを扱えます。

───────────────────────────────────────────────────────────────────────────
> Describe your next engineering task here...
───────────────────────────────────────────────────────────────────────────

プロンプトの送信

エージェントのターンを開始するには、プロンプトパネルに指示を入力して Enter を押します。エージェントはただちに現在のディレクトリ（ワークスペース）を分析し、必要な設定を読み込み、実行プランの作成を開始します。

実行中セッションの中断

エージェントが意図しないタスクを始めたり、コマンド実行中にループに陥ったりした場合は、Esc を押すとセッションを即座に停止できます。

ヒント

万能のエスケープ: Esc キーはグローバルな脱出口として機能します。Esc を押すと、実行中のエージェントのターンを即座にキャンセルし、オーバーレイパネルを閉じ、クリーンなプロンプトボックスへフォーカスを戻します。

複数行の入力

複雑な指示、構造化されたテストシナリオ、複数段落にわたる指示には、組み込みの複数行機能を利用します。

改行の挿入ショートカット

  • 標準: Shift+Enter または ctrl+j を押すと、送信せずに現在のプロンプト内へ改行を挿入できます。
  • macOS ターミナルでの代替手段: Apple のターミナル（既定では Shift+Enter を転送しません）を使用している場合は、Option+Enter を押します。ターミナルの環境設定プロファイルで Use Option as Meta key（Option キーを Meta キーとして使用）にチェックが入っていることを確認してください。
  • バックスラッシュによる汎用エスケープ: 現在の行末に末尾のバックスラッシュ \ を入力して Enter を押します。CLI は自動的にバックスラッシュを削除し、改行を挿入します。

$EDITOR でプロンプトを編集する

大規模なプロンプトを普段の開発用エディタで作成・編集するには、次の手順を行います。

  1. 空のプロンプトパネル内で ctrl+g を押します。
  2. CLI がシステム既定のテキストエディタ（vim、nano、code など。/config または環境の $EDITOR 変数で設定）を起動します。
  3. 一時的なエディタバッファ内で複数行の指示を作成します。
  4. エディタを保存して終了します。CLI は編集したバッファを自動的にターミナルのプロンプトへ取り込みます。

メディアの添付

Antigravity CLI は、システムのクリップボードからリッチメディア形式を直接貼り付けることをサポートしています。プロンプトパネル内で ctrl+v（またはターミナル本来の貼り付け操作）を押すと、スクリーンショットのモックアップや動画の録画を添付できます。

対応するファイル形式

  • 画像: PNG、JPEG、GIF、WebP、BMP、TIFF、SVG。
  • 動画: MP4、MOV、WebM、AVI。

次のステップ

操作パターンを習得したら、エージェントがどのようにアクションを提示し、確認を求めるかを確認しましょう。

  • アーティファクトの確認: ファイル編集、プラン、テスト実行の検査と管理方法を学びます。
  • 会話の管理: 過去のスレッドを再開し、実行中のセッションをフォークします。
  • バックグラウンドタスクとサブエージェント: 非同期で動くバックグラウンドエージェントを監視します。
