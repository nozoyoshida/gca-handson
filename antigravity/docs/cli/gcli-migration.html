Gemini CLI からの移行

出典: antigravity.google/docs/gcli-migration（公式ドキュメントの日本語要約）

レガシーな構成の変換、Gemini CLI の拡張機能のネイティブプラグインとしてのインポート、カスタムスキルのパスの調整、Model Context Protocol 構成の再フォーマットを行います。

概要

Antigravity CLI は、Gemini CLI で普及した中核的な開発者体験の構成要素との後方互換性を維持しています。スムーズなアップグレードを実現するために、CLI は自動オンボーディング変換と、明示的な CLI 移行コマンドのシーケンスの両方を提供します。

初回起動時のオンボーディング

レガシーな構成を含む環境で agy を初めて実行すると、CLI は既存のプロファイルを自動的に検出します。インタラクティブなチェックリストが表示され、どのアセットを移行するかを選択するよう促されます。

  1. 自動変換: 変換したい拡張機能とグローバル構成を選択します。
  2. キーリングへの保存: CLI は、アクティブなセッショントークンを、オペレーティングシステムのネイティブなキーリングストレージへ安全に移行します。
  3. 設定の整合: デフォルトの表示パラメータとレンダリングバッファが、新しい設定プロファイルへ自動的にマッピングされます。
メモ
部分的な互換性: ワークスペースのスキル、ルール、MCP サーバーのサポートは維持されますが、Gemini CLI の一部のカスタマイズされたターミナルテーマや実験的なビジュアルオーバーレイはサポートされない場合があります。

拡張機能のプラグインへの変換

Gemini CLI の登場以降、業界では plugins（プラグイン）という用語が標準化されました。次のコマンドを実行することで、レガシーな Gemini 拡張機能をネイティブな Antigravity プラグインへ手動で変換できます。

agy plugin import gemini

このユーティリティは、レガシーなローカルディレクトリを検索し、拡張機能のマニフェストを解析して、ファイルをネイティブなレイアウトブロックへ変換します。

コンテキストファイルとワークスペースのルール

両方の CLI プラットフォームは同一のワークスペースコンテキストルールを利用します。既存のルールドキュメントを変更する必要はありません。

  • ワークスペースのローカルコンテキスト: エージェントは引き続き、アクティブなディレクトリ内の GEMINI.md および AGENTS.md ファイルで定義されたルール制約を解析・適用します。
  • グローバルな開発者コンテキスト: エージェントは ~/.gemini/GEMINI.md にあるグローバルな制約を自動的に参照・適用します。

更新されたスキルのパス

グローバルに共有されるスキルはユーザーのホームディレクトリに残りますが、ワークスペース固有のローカルスキルの対象フォルダパスは更新されました。

構成Gemini CLIAntigravity CLI
グローバル共有パス~/.gemini/skills/~/.gemini/antigravity-cli/skills/
ワークスペースのプロジェクトパス.gemini/skills/.agents/skills/
注意
要対応: プロジェクトに .gemini/skills/ で定義されたカスタムのワークスペーススキルがある場合、Antigravity エージェントがそれらをアクティブなスラッシュコマンドとして認識できるように、フォルダを手動で .agents/skills/ へリネームまたは移動する必要があります。

MCP 構成のフォーマット変更

Antigravity CLI は、Model Context Protocol サーバーを主要な設定構成の中にネストするのではなく、専用の軽量な JSON プロファイルへ分離します。

ディレクトリのマッピング

  • レガシーな Gemini 構成: サーバーは ~/.gemini/settings.json 内にインラインで宣言されていました。
  • Antigravity CLI の構成: サーバーはスタンドアロンの mcp_config.json プロファイル内に定義されます。
    • グローバルサーバー: ~/.gemini/config/mcp_config.json
    • ワークスペースサーバー: .agents/mcp_config.json

必要なスキーマの更新

リモートの websocket または SSE サーバー定義を手動で移行する際は、URI のキーパラメータを現在の標準に合わせて更新します。

  • レガシーなスキーマキー: url または httpUrl
  • 現在のスキーマキー: serverUrl
{
  "mcpServers": {
    "remote-indexer": {
      "serverUrl": "https://mcp.internal.enterprise.com/sse",
      "env": {
        "AUTH_TOKEN": "secure_alpha_token"
      }
    }
  }
}
