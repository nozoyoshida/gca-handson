AGY CLI の使い方

出典: antigravity.google/docs/cli-using（公式ドキュメントの日本語要約）

設定（Settings）

Antigravity CLI は、ワークスペースの挙動、安全制限、エディタの設定、見た目のスタイル、パフォーマンスなどをカスタマイズするための柔軟な設定システムを備えています。

  • 設定ファイル: プレーンな JSON ファイル ~/.gemini/antigravity-cli/settings.json に保存されます。
  • 設定パネル: /config または /settings と入力すると、利用可能なすべてのオプションを一覧表示するフルスクリーンのオーバーレイメニューが開きます。
    • 設定を選択すると、そのオプション一覧またはテキスト入力フィールドが開きます。
    • 選択した内容は即座にディスクへ保存され、メインの一覧に戻ります。
  • オーバーライド: 一部の設定は、起動時に CLI フラグ（例: --sandbox や --dangerously-skip-permissions）で上書きできます。
    • 設定メニューには、オーバーライドの出所を示すインジケータが表示されます（例: Sandbox Mode on overridden by --sandbox）。
    • ディスク上の永続設定は引き続き編集できますが、現在のセッションでは再起動するまでコマンドラインのオーバーライドが優先されます。

キーバインド（Keybindings）

AGY CLI ではキーバインドをカスタマイズできます。/keybindings と入力するか、JSON ファイルを直接編集して変更できます。

  • ファイルの場所: ~/.gemini/antigravity-cli/keybindings.json
  • リセット: デフォルトに戻すには、keybindings.json ファイルを削除します。

デフォルトのキーバインド

コマンドの編集e提案されたターミナルコマンドを編集するためにエディタを開く

改行の挿入alt+enter, ctrl+j, shift+enter送信せずにプロンプトへ改行を追加する

JSON ファイルでは、1 つの操作に複数のキーバインドを割り当てられます。キーバインドを無効にするには、リストを空（例: []）に設定します。ファイルが不正な形式の場合、CLI は有効な部分を使用し、壊れた操作についてはデフォルトにフォールバックします。

注意
重要: キーバインド cli.exit と cli.enter は無効化できません。
