プラグイン（Plugins）

プラグインの仕組み

プラグインは名前空間付きのバンドルで、スキル、エージェント、ルール、MCP サーバー、フックを 1 つのデプロイ可能なユニットとしてまとめられます。

プラグインをインストールすると、CLI はそのファイルをホームディレクトリ配下の ~/.gemini/antigravity-cli/plugins/<plugin_name>/ に配置（ステージング）します。Antigravity Agent は、配置されたこれらのカスタマイズを自動的に検出して読み込みます。

~/.gemini/antigravity-cli/
├── plugins/
│   └── <plugin_name>/
│       ├── plugin.json         # Required marker file
│       ├── mcp_config.json     # Optional MCP server definitions
│       ├── hooks.json          # Optional event hooks definition
│       ├── skills/             # Optional skills
│       ├── agents/             # Optional subagents
│       └── rules/              # Optional rules
└── import_manifest.json        # Tracking manifest

プラグインコンポーネントへのアクセス

ステージングされて読み込まれた後は、CLI 内でスラッシュコマンドを使ってプラグインのコンポーネントを操作できます。

ターミナルサンドボックス（Terminal Sandbox）

ターミナルサンドボックスは軽量なセキュリティ隔離の仕組みで、エージェントがローカルのシェルコマンドを実行する際に、破壊的なファイル操作や許可されていないアウトバウンドのネットワークリクエストからホストシステムを保護します。

重い仮想マシンやコンテナを動かすのではなく、CLI はネイティブな OS の機能（Linux では nsjail、macOS では sandbox-exec、Windows では AppContainer）を活用して、起動オーバーヘッドなしで厳格な封じ込め境界を適用します。

設定

サンドボックスの挙動は、settings.json ファイル（~/.gemini/antigravity-cli/settings.json にあります）で設定できます。

{
  "enableTerminalSandbox": true
}
  • enableTerminalSandbox（boolean、デフォルト: false）: すべてのローカルエージェントプロセスに対して、一般的な実行封じ込めの障壁を有効にします。

インタラクティブな承認

エージェントが確認を必要とするターミナルコマンドを提案すると、CLI のプロンプトは設定に応じて動的に変化します。

  • サンドボックスが有効な場合: 単一の信頼できるコマンドについて一時的に封じ込め境界を回避したいときのために、確認プロンプトには Yes, and run without sandbox restrictions という専用の選択肢が含まれます。
  • サンドボックスが無効な場合: 特定の、潜在的に危険なコマンドを安全境界内で強制的に実行したいときのために、プロンプトには Yes, and run in sandbox という選択肢が含まれます。

CLI スラッシュコマンドリファレンス

Antigravity CLI は、プロンプトボックスに直接入力するさまざまなスラッシュコマンドをサポートしており、会話の管理、設定の構成、エージェントの機能の確認などを行えます。

主要なスラッシュコマンド（Core Slash Commands）

コマンドカテゴリ用途
/resume（エイリアス /switch）会話会話ピッカーを開いてセッションを再開または切り替える。
/rewind（エイリアス /undo）会話会話履歴を以前のチェックポイントまで巻き戻す。
/rename <name>会話追跡しやすいように、現在の会話スレッドの名前を変更する。
/permissions設定エージェントの自律レベル（request-review、always-proceed、strict）を選択する。
/model設定デフォルトの推論モデルを選択する（セッションをまたいで保持される）。
/keybindings設定インタラクティブなキーボードショートカットエディタを開く。
/statusline設定CLI のステータスバーに表示されるリアルタイムインジケータをカスタマイズする。
/tasksツールと監視実行中のバックグラウンドタスクを監視・ログ表示・終了する。
/skillsツールと監視ローカルおよびグローバルのカプセル化されたエージェントワークフローを閲覧する。
/mcpツールと監視Model Context Protocol サーバーを設定・管理するパネルを開く。
/open <path>ユーティリティファイルを優先する外部エディタですぐに開く。
/usageユーティリティターミナル内でインラインのインタラクティブなヘルプマニュアルを開く。
/logoutアカウントGoogle セッションからログアウトし、キャッシュされた認証情報を消去する。

settings.json による高度なカスタマイズ

パワーユーザー向けに、いくつかのスラッシュコマンドは ~/.gemini/antigravity-cli/settings.json 設定による詳細なカスタマイズに対応しています。

  • きめ細かい権限: グローバルなレベルの代わりに、許可/拒否する特定のコマンドを定義します。 
    "permissions": {
  "allow": ["command(git)", "command(npm test)"],
  "deny": ["command(rm -rf)"]
}
  • カスタムのステータスラインとウィンドウタイトル: ライブのエージェントメタデータ（CWD、アクティブモデル、トークン使用量、状態などを含む JSON 形式）を独自のシェルスクリプトへ直接パイプして、動的なステータスバーやターミナルのウィンドウタイトルを生成できます。

Antigravity CLI のサブエージェント（Subagents）

Antigravity CLI は非同期のサブエージェントフレームワークを備えており、メインエージェントが並行作業の委譲、バックグラウンドでの調査、システムテストの実行を、アクティブな会話をブロックせずに行えます。

サブエージェントとは

サブエージェントは独立した並行エージェントセッションで、特定のバックグラウンドタスクをメインの会話と並行して処理するために設計されています。

  • 目的: メインエージェントは、ドキュメントの検索、ビルドの実行、修正の検証といったバックグラウンド操作を行うために、自動的にサブエージェントを生成します。
  • 機能: サブエージェントは、コード検索、ファイル編集、ターミナルコマンド、Web 検索などのツールにフルアクセスして、割り当てられたタスクを完了します。
    • メインエージェントは、サブエージェントがどのツールと権限を得るか（MCP ツールを使えるか、ファイルを書き込めるかを含む）を決定します。

エージェントの管理: /agents パネル

Antigravity CLI は、実行中のサブエージェントを表示・管理し、アクションを承認するためのインタラクティブなターミナル UI を提供します。

  • アクセス: プロンプトに /agents と入力すると、サブエージェントパネルが開きます。
  • 概要: パネルには、アクティブおよび完了したサブエージェントの一覧が表示され、ステータス（running、done、killed など）や現在実行中のステップといった概要レベルの詳細が示されます。
メモ
パネルからサブエージェントを選択すると、フルスクリーンの詳細ビューが開きます。このビューには、サブエージェントの会話の全体像（ステップ、思考、ツール実行ログを含む）が表示されます。

ツールの確認と承認

サブエージェントが、ユーザーの権限を必要とするツール（ローカルコマンドの実行やファイルの書き込みなど）を実行しようとすると、そのリクエストが提示されます。承認は次の 2 つの方法で管理できます。

  1. 詳細ビューでの承認
    サブエージェント詳細ビューには、保留中のすべての承認を含むインタラクションセクションがあり、リクエストを選択的に承認または拒否できます。
    ヒント
    ヒント: キーボードショートカット ctrl+j を使うと、メインの会話から、承認待ちの次のサブエージェントの詳細ビューへ直接「テレポート」できます。
  2. Fast Path アラート
    作業の流れを保てるように、サブエージェントが権限を要求すると、Antigravity CLI はプロンプトボックスのすぐ上に Fast Path アラートを表示します。
    ヒント
    ヒント: メインの会話から離れることなく、ctrl+k を使って保留中のサブエージェントの権限を即座に承認できます。
