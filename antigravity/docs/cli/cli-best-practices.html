ベストプラクティス

出典: antigravity.google/docs/cli-best-practices（公式ドキュメントの日本語要約）

ワークフロー、プロンプトの構成、ローカル設定の選び方を習得し、堅牢な制御を保ちながらエージェントの速度を最大化します。

検証ループを確立する

自律エージェントから信頼できる正確な変更を確実に得るために最も効果的な方法は、エージェントにローカルな検証手段（ユニットテスト、ビルドコマンド、フォーマット用スクリプトなど）を与えることです。

エージェントにコード変更を依頼する前に、次を行います。

  1. ワークスペースのディレクトリにテストスイートが用意されていることを確認します。
  2. テストが存在しない場合は、まず標準的なテストブロックを書くようエージェントに指示します。
  3. エージェントがコードを提案したら、その成果を検証するためにローカルのテストコマンドを実行するよう指示します。
  4. エージェントがコマンドを実行し、テスト出力をもとに自動的に反復改善する様子を確認します。
> Implement feature X in main.py. Run npm test afterward to verify the build.

探索し、計画し、それから実行する

自律的なローカルエージェントは、複雑な変更を「探索」「計画」「実行」という明確なフェーズに分割したときに最も高い精度で動作します。

  • 探索: 変更を書き始める前に、対象のコードベースが特定の問題をどのように解決しているか、あるいはインターフェースがどこで定義されているかを説明するようエージェントに依頼します。
  • 計画: 実装プランを要求します。エージェントは、対象ファイル、必要な依存関係、ロジックの上書き内容を実装プランのアーティファクトとして列挙します。
  • 実行: 構造化されたプランを承認したら、編集を適用するようエージェントに指示します。
> Explore how our router resolves `/docs/:page`. Write down an implementation plan to add `/docs/best-practices`.

プロンプトのコンテキストを充実させる

ローカルエージェントに高精度な手がかりを与えて、推論の範囲を絞り込み、トークンのオーバーヘッドを最小化します。

対象ファイルの自動補完

プロンプトボックス内で @ を入力すると、インタラクティブなパス候補のオーバーレイが表示されます。パスを選択すると、ワークスペース内のファイルの絶対パスがプロンプトに直接取り込まれます。これにより、エージェントはコード検索の対象を絞り込めます。

視覚的な証拠を添付する

視覚的な UI の問題、描画のバグ、フロントエンドのレイアウト崩れをデバッグする場合は、スクリーンショットや動画を撮影してコピーし、プロンプトボックス内で ctrl+v を押して添付します。エージェントはそのメディアファイルを参照して問題を診断します。

ワークスペース環境を設定する

ローカルワークステーションのルールとセキュリティ境界を、自分の開発フローに合わせて最適化します。

コードベースのルールファイルを書く

ワークスペースのルートに GEMINI.md または AGENTS.md ファイルを作成し、ディレクトリ固有の規約、スタイルの方針、テストコマンドのパラメータ、非推奨に関する注意点を記述します。エージェントは起動時にこれらのルールを自動的に解析し、変更を提案する前に参照します。

構造化された権限を設定する

プロジェクトのリスクレベルに応じて、~/.gemini/antigravity-cli/settings.json でセーフティバリアを調整します。

  • request-review（既定）: 書き込み操作、bash コマンド、リモートへのネットワーク呼び出しを実行する前に確認を求めます。
  • proceed-in-sandbox: すべてのターミナル実行をセキュアなサンドボックスの封じ込め領域に制限します。安全なコマンドは自律的に実行され、リスクのあるコマンドは確認を求めます。
  • strict: 読み取り以外のすべての操作について常に確認を求め、1 行単位での完全な透明性を提供します。
{
  "toolPermission": "proceed-in-sandbox",
  "enableTerminalSandbox": true
}

TUI セッションを能動的に管理する

実行中のセッションナビゲーション機能を活用して、行き詰まりから回復したり、途中でループに陥ったエージェントを軌道修正したりします。

早めに軌道修正する（esc）

エージェントが誤った検索パターンを実行したり、意図から外れたコードを書いたりしているのを見たら、グローバルな脱出口キーである esc をすぐに押してターンを中断し、クリーンなプロンプトのフォーカスを取り戻します。

/rewind で履歴を巻き戻す

エージェントが連続して複数の変更を行い、ビルドエラーを引き起こしてしまった場合でも、セッションを破棄する必要はありません。/rewind（または /undo）を入力すると、会話スレッドを以前の安定したチェックアウト状態まで巻き戻せます。

/fork で実験を分岐させる

最適な実装方針が分からない場合は、次のようにします。

  1. 安定したベースラインのスレッドに到達します。
  2. /fork を入力して、並行する複製セッションを立ち上げます。
  3. 分岐したセッションで、試験的なコード変更を試します。
  4. そのアプローチが失敗したら、/resume を実行して安定したメインのブランチに戻します。

自動化とスクリプト化

Antigravity CLI は、標準的なシェルのパイプラインツールの中でシームレスに動作するよう設計されています。

非対話型コマンドを実行する（-p）

簡単なクエリを自動化したり、エージェントを git フックに組み込んだりするには、ワンショットのプロンプトフラグ -p を使用します。

agy -p "Review this git diff and draft a conventional commit message" --cwd $(pwd)

並列サブエージェントでファンアウトする

大規模な一括処理や複数ファイルにまたがるリファクタリングでは、並行して動くバックグラウンドのサブエージェントを生成するよう主エージェントに指示します。エージェントマネージャーがバックグラウンドのスレッドを自律的に処理する間、あなたはメイン画面で作業を続けられます。

関連リソース

設定の方法や視覚的なレイアウトのカスタマイズについて学びます。

  • 設定、表示、キーバインド: キーボードのホットキーやバッファをカスタマイズします。
  • 権限とサンドボックス: ファイルシステムの封じ込めを適用します。
  • プラグインとスキル: 独自のカスタムスラッシュコマンドを作成します。
