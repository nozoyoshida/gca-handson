チュートリアル

出典: antigravity.google/docs/cli-tutorial（公式ドキュメントの日本語要約）

Antigravity CLI の起動方法、自律的なローカルエージェントとの協働、生成されたファイルのレビュー、ターミナルでのテストコマンドの実行を学びます。

概要

このガイドでは、すばやく始めるためのオンボーディング演習を順を追って説明します。自律エージェントに指示して Python のユーティリティスクリプトを作成させ、変更内容をレビューし、その実行を検証します。

手順（Step-by-step）

  1. クリーンなプロジェクトディレクトリを作成し、Antigravity の TUI を起動します。

    mkdir agy-demo && cd agy-demo
agy
    メモ
    初回起動: agy を初めて実行する場合は、ターミナルの指示に従ってサイレント認証を完了してください。トラブルシューティングの詳細は Installation & Auth（cli-install） を参照してください。

  2. エージェントに Python のスクレイピングスクリプトを生成するよう指示します。

    画面下部のプロンプトボックスに次の指示を入力し、Enter を押します。

    Write a simple python script to fetch web page text

    エージェントはワークスペースを読み取り、ファイルが存在しないと判断して、スクリプトを作成する計画を立てます。エージェントが推論を行いアクションをスケジュールする様子が、リアルタイムの更新として表示されます。

  3. アーティファクトのレビュー画面を開いて、提案されたコードを確認します。

    エージェントがファイルの生成を終えると、通知が表示されます。ctrl+r を押して Artifact Review 画面に入ります。

    • ↑/↓ を使って、新しく作成された main.py へ移動します。
    • ファイルの内容全体と差分（diff）をレビューします。
    • y を押して main.py の作成を承認します。
    • Esc を押してレビューパネルを閉じ、メインのプロンプトに戻ります。

  4. エージェントと一緒にテストコマンドを実行して、出力を検証します。

    Python スクリプトを実行して挙動を検証するよう、エージェントに指示します。プロンプトボックスに次のコマンドを入力し、Enter を押します。

    Run the python script and show me the output

    エージェントは python3 main.py の実行を提案します。y を押して確認し、コマンドを実行します。エージェントはスクリプトをローカルで実行し、その標準出力をターミナル画面へ直接ストリームします。

  5. Antigravity セッションを終了します。

    タスクが完了したら、プロンプトボックスで ctrl+d を押す（または /exit と入力する）と、TUI が閉じて元のシェルセッションに戻ります。

次のステップ

最初のエージェント支援ワークフローを実行できたので、次は CLI の設定方法と中核となる概念を学びましょう。

  • Installation & Auth（cli-install）: agy のインストールと SSH プロファイルのセットアップに関する詳細な手順。
  • プロンプトと操作（Prompting & Interaction）: 複数行入力、メディアファイルの貼り付け、実行中の割り込み操作のベストプラクティス。
  • Reviewing Artifacts（cli-artifacts）:「Trust through Transparency（透明性による信頼）」というアーキテクチャパターンの詳細解説。
