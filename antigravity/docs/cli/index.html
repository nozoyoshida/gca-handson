この資料について 要確認
本ページ群は公式ドキュメント（antigravity.google/docs/cli-*）の内容を日本語で要約・整理したものです。各ページ上部に出典リンクを記載しています。Antigravity はアップデートが速いため、コマンドやフラグの最終確認は必ず公式ドキュメントで行ってください。設定ファイルは ~/.gemini/antigravity-cli/settings.json、CLI のバイナリ名は agy です。
