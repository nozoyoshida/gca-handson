ステータスライン

出典: antigravity.google/docs/cli-statusline（公式ドキュメントの日本語要約）

標準のステータスライン構成要素の切り替え、カスタムスクリプト構成の定義、動的な JSON 状態ペイロードの整形を行います。

概要

ステータスラインは TUI プロンプトパネルの最下部に表示されます。アクティブなエージェントのサイクル、ワークスペース環境、コンテキストトークンウィンドウの使用状況、バックグラウンド実行タスクなどのコンテキストを一目で把握できます。

対話型の切り替え

  1. プロンプトボックスで /statusline と入力し、Enter を押します。
  2. 対話型の ステータスピッカーパネル（Status Picker Panel） オーバーレイが開きます。
  3. ↑ / ↓ を使って、特定のメトリクス要素（アクティブなモデル、タスクカウンター、コンテキスト割合など）の表示・非表示を切り替えます。
  4. Enter を押すと選択を確定して終了します。Esc を押すとキャンセルします。

カスタムステータスラインスクリプト

高度なターミナルレイアウトやカスタムステータスバー表示のために、アクティブなエージェントのメタデータをカスタムスクリプトへ渡すことができます。

設定

~/.gemini/antigravity-cli/settings.json ファイルに statusLine 設定ブロックを追加します。

{
  "statusLine": {
    "type": "command",
    "command": "~/.gemini/antigravity-cli/statusline.sh"
  }
}

エージェントの状態が変化するたびに、TUI はあなたのコマンドスクリプトを実行し、詳細な状態 JSON ペイロードをスクリプトの stdin に直接パイプし、stdout から整形済みの文字列を読み取って、プロンプトのステータスラインにその結果をレンダリングします。フルの ANSI カラーコードがサポートされます。

利用可能な JSON フィールド

スクリプトにパイプされる JSON ペイロードには、次のトップレベルフィールドが含まれます。

フィールド型説明
cwdstring現在の作業ディレクトリ
conversation_idstring現在の会話 ID
modelobjectアクティブなモデルの id と display_name
productstringアプリケーション名（例: antigravity-cli）
workspaceobjectcurrent_dir と project_dir のパス
versionstringCLI のバージョン文字列
plan_tierstring認証済みユーザーのサブスクリプションティア
emailstring認証済みユーザーの LDAP / メールアドレス
agentobjectアクティブなエージェントプロファイル名
context_windowobjecttotal_input_tokens、total_output_tokens、context_window_size、used_percentage、remaining_percentage、current_usage
agent_statestring現在の状態: idle、thinking、working、tool_use、initializing
vcsobjectバージョン管理情報: type（git/jj/fig）、branch、client、dirty
sandboxobjectサンドボックス設定: enabled、allow_network
subagentsarrayアクティブなサブエージェントセッション（name、role、status）
artifactsarray生成されたアーティファクト（uri、status、type）
pending_input_countintキューに入っているユーザーメッセージの数
background_tasksarray実行中のタスク（name、status、index）
tool_confirmation_pendingboolツール確認ダイアログが表示されているかどうか
terminal_widthint対話型ターミナルのライブな幅

  "context_window": {
    "total_input_tokens": 88244,
    "total_output_tokens": 61074,
    "context_window_size": 1048576,
    "used_percentage": 8.415603637695312,
    "remaining_percentage": 91.58439636230469,
    "current_usage": {
      "input_tokens": 63382,
      "output_tokens": 346,
      "cache_creation_input_tokens": 0,
      "cache_read_input_tokens": 20857

  "product": "antigravity-cli",
  "agent_state": "idle",
  "vcs": {
    "type": "git",

  },

    "enabled": false
  },
  "plan_tier": "Pro",

サンプルスクリプト

完全でレイアウト適応型のスクリプトを、公式の GitHub 上の statusline.sh の例 からダウンロードできます。このスクリプトは状態バッジを描画し、アクティブなブランチを処理し、コンテキストウィンドウの進捗バーを動的に整形します。

スクリプトを ~/.gemini/antigravity-cli/statusline.sh に保存し、実行可能にします。

chmod +x ~/.gemini/antigravity-cli/statusline.sh

関連項目

  • ターミナルタイトルのカスタマイズ: 動的なウィンドウタイトルを設定します。
  • 設定（settings.json）: キーボードホットキーとバッファをカスタマイズします。
  • 権限とサンドボックス: 安全なディレクトリ権限を管理します。
